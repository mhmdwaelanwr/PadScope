# UI polish validation checklist

- [ ] Tab headers have clear spacing at the default window size.
- [ ] Active tab border and cyan indicator stay inside the header area.
- [ ] Source Device combo box is readable in dark theme.
- [ ] Virtual Target combo box remains dark when disabled.
- [ ] Drop-down items use PadScope dark surfaces and readable text.
- [ ] Light theme updates combo surfaces and text correctly.
- [ ] Theme switching can be repeated without stale colors.
- [ ] Segoe UI Variable is used when available, with Segoe UI fallback.
